# iOS Projects

A collection of small iOS projects created while learning and practicing native iOS development with Swift and UIKit.

This repository contains focused exercises covering common iOS concepts such as layouts, navigation, table views, data passing, browser views, and basic application interactions.

> **Project Note**
>
> These are older learning projects and are preserved as part of my iOS development journey.
>
> They reflect the concepts and development practices I was learning at that stage and are not intended to represent my current architecture or engineering approach.

## Projects

The repository includes projects such as:

- **AutoLayout** — layout and constraint practice
- **BrowserApp** — basic browser/web navigation
- **CardWorkoutApp** — simple workout-focused UI
- **CarouselSlider** — carousel-style interface
- **NamesToFaces** — image and data handling
- **PassingDataBetweenVCs** — passing data between view controllers
- **RandomColorGenerator** — basic UI interaction
- **SwiftyWords** — word-based iOS project
- **TableViewList** — UITableView fundamentals
- **WordScramble** — word game and input handling

## Running a Project

Clone the repository:

```bash
git clone https://github.com/himanshu240601/ios-projects.git
cd ios-projects
```

Open any individual project folder and launch its `.xcodeproj` file in Xcode.

For example:

```bash
open AutoLayout/AutoLayout.xcodeproj
```

Select an iOS simulator or physical device and run the project.
